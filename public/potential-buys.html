Send screenshots from your iPhone (Share Sheet Shortcut)

Opening this page on your phone and tapping + Add screenshots works too. The Shortcut lets you send straight from Photos or a screenshot preview with Share → Potential Buys.

  1. In Shortcuts, make a new shortcut named Potential Buys. In its details, turn on Show in Share Sheet and set it to receive Images.
  2. First add Ask for Input (Text) with the prompt Ticker?. It goes before the repeat, so one answer covers every screenshot you share at once.
  3. Add Repeat with Each item in Shortcut Input (so several screenshots go at once).
  4. Inside the repeat, add Convert Image → JPEG (camera photos are HEIC, which browsers can't show).
  5. Then Get Contents of URL:
    • URL: /api/potential-buys/upload
    • Method POST. Header x-broadcast-key = your BROADCAST_LEDGER_API_KEY (the same key as the phone briefings Shortcut).
    • Header x-ticker = Provided Input (the answer to Ticker?).
    • Request Body File = Converted Image.
  6. Optional: Get Dictionary Value message from Contents of URL, then Show Notification with it. It reads Saved to $NVDA, or tells you what was wrong. Worth adding: the Shortcut doesn't stop when the upload is refused, so without it a failed send looks like it worked.

Type the ticker as nvda, $NVDA or NASDAQ:NVDA; each lands in the $NVDA stack here, with any earlier NVDA screenshots. Leave it blank to save without one and add it here later. To add a note as well, send it in an x-label header (for example breakout becomes $NVDA breakout).

The key can only add screenshots here. Viewing, relabelling and deleting them still needs your login.
