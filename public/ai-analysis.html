ℹ️ How this page works
  1. Pick a card and timeframe. Every card is one TradingView symbol, banded into crypto pairs, dominance ratios, and stocks/macro. The dropdown on the card sets its timeframe (15m through 1M).
  2. Analyze. The server renders that symbol as a standard dark TradingView chart — candles plus Volume, MACD, and RSI — in a headless browser and screenshots it.
  3. Read. The screenshot goes to an OpenAI vision model, which answers in short bullets (Trend, Levels, Momentum, Risk, Final call) and ends on BUY, SELL, or HOLD. That last word becomes the coloured verdict chip.
  4. Broadcast. Optional — pushes the chart image and the read to your Telegram groups. A generation can only be sent once; run Analyze again to re-arm the button.
  • AI use: Yes. Analyze sends the rendered chart screenshot to an OpenAI vision model for the written read and verdict.
  • Opening this page costs nothing: it only replays the last saved result per symbol and timeframe. Only Analyze calls the model, and re-running it within 30 minutes reuses the cached result.
  • A green ✓ badge means the read was generated today; grey means an older day. If OpenAI rate-limits a request, the card shows ⌛ and keeps the previous read for about five minutes before retrying.
  • Analyze and Broadcast ask for the admin key. Everything else on the page is read-only.
  • Each verdict is a model's read of a single chart image — a prompt to look closer, not financial advice.
